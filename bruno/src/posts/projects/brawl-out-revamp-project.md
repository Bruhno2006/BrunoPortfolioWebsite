BRAWL-OUT is a text-based local, multiplayer game created using the Python programming language. With it's simple presence, it was really easy to grow the game with more weapons, movement options, and functionality. This as a result left the game to be unnecessarily large, complicated to read and debug at times - especially for a unexperienced programmer at the time.

In 2025, with my improved programming skills and better understanding of Python, I aimed to revamp my old card-game program with minimal and readable code to better manage and debug from, a fairer battle system, while still implementing new features to gameplay and player navigation.
